GitHub Portfolio Check

A free, self-service tool that gives students coaching-style feedback on how their GitHub profile and projects come across to a recruiter.

Try it: njaraya504.github.io/techportfolio-check

Overview

Students often ask how to apply portfolio advice to their own GitHub, and whether their profile is ready to share with employers. This tool answers that question in a few minutes. A student enters their GitHub username, picks the projects they would show a recruiter, and gets a score out of 100 with specific, encouraging feedback on what to improve next.

The checks are based on the Building a Technical Portfolio guide, which covers what recruiters look for in a technical portfolio: a professional profile, clear project names, complete READMEs, clean files, and a steady commit history.

What It Checks

Profile setup

A bio that describes the student's focus area
A professional username
Links to LinkedIn or other platforms
A Profile README that works like an elevator pitch

Projects

At least three documented projects
README sections recommended in the guide: Overview, Key Features, Tools and Technologies, Outcomes, How to Run, and What I Learned
A screenshot, demo, or live link a recruiter can see without running the code
Clear repository names and one-line descriptions
Leftover test files, draft-style filenames, and other clutter
Work pushed in small commits over time, rather than one large upload

A few things GitHub doesn't share publicly, such as pinned repositories and profile photo quality, are covered with quick yes or no questions.

How Students Use It
Open the tool and enter a GitHub username.
Choose the three to five projects you have pinned, or plan to pin.
Read your feedback. Start with the "Where to start" list, which is ordered by impact.
Use the README and Profile README starters to fill in missing sections.
Copy your report and bring it to a career coaching appointment.
Feedback, Not Just a Score

Every item explains what the tool noticed, why it matters to a recruiter, and one concrete step to try. Each project gets a "What's working" list alongside suggestions, so students see their strengths before their gaps.

What It Doesn't Do

This tool looks at how work is presented. It does not review code, evaluate technical quality, or advise on programming decisions. For technical questions, students should connect with their professors and academic department.

Privacy

Everything runs in the student's own browser using GitHub's public data. Nothing is saved, stored, or sent anywhere.

Good to Know

GitHub limits how many lookups one network can make each hour. On shared Wi-Fi during a busy workshop, students may see a message asking them to try again later. Switching to phone data solves it.

Tools and Technologies

HTML, CSS, and JavaScript in a single file, with no installation needed
GitHub REST API for public profile and repository data
Hosted on GitHub Pages
